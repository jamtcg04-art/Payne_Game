# Static Hours

Original third-person noir shooter (Godot 4). Game plan: `docs/game-plan/00_README.md`.

## Getting started
1. Install Godot 4.4+ (standard build).
2. Open `project.godot`. The main scene is `scenes/levels/Boot.tscn`.
3. Supply third-party assets locally under `assets/third_party/` (gitignored except CC0 packs).
4. Smoke test: `godot --headless --quit-after 300 res://scenes/levels/Boot.tscn`.

See `docs/game-plan/` for the plan and milestones (this is M0).
